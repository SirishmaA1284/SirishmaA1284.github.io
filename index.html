Computer vision · Accessibility
Hand Gesture Recognition for Smart Homes
A contactless way for elderly and disabled people to control lights and fans. An EfficientNetB0 model with MediaPipe hand landmarks recognises eight gestures, trained on a custom dataset with varied lighting, backgrounds and hand angles. Depth filtering cuts false triggers, live Grad-CAM shows what the model is looking at, and a motion-based fallback still works when a gesture can't be made precisely.
TensorFlow · MediaPipe · OpenCV · Grad-CAM · Arduino

      
Algorithms · GPU computing
String Matching Algorithms on GPU
Brute Force, KMP, Boyer-Moore, Boyer-Moore-Horspool and a Rabin-Karp + FSA hybrid, compared on the Reuters-21578 news corpus for speed, memory use and scalability. Each was also rewritten as a parallel GPU version with CUDA. Horspool was the fastest overall, and GPU acceleration sped up every algorithm, which matters for large-scale text search in security and bioinformatics.
Python · NumPy · CUDA (Numba / PyCUDA)

      
Bioinformatics
DNA Sequence Classification
Classifies genome sequences from humans, eagles and fish using KNN, Logistic Regression and SVM. The models were trained on labelled genome data and compared per species: Logistic Regression was best for human (92%) and eagle (87.6%) DNA, while SVM led for fish (90.2%).
Python · Scikit-learn · KNN · SVM

      
Regression · Education
Predicting Student Performance
Forecasts student scores from demographics, past grades, attendance and study habits so teachers can spot students who need help before exams. Support Vector Regression was tested with several kernels; RBF gave the best fit, measured by MSE and R² score, with Matplotlib charts to explain the results.
Python · Pandas · Scikit-learn (SVR) · Matplotlib

Mall Customer Segmentation
Groups mall shoppers by age, income and spending behaviour to guide targeted campaigns and loyalty offers. K-means, hierarchical clustering and Gaussian Mixture Models were compared on a Kaggle dataset, with the elbow method and silhouette score used to choose and validate the clusters, then each segment was turned into a marketing profile.
Python · Scikit-learn · K-means · GMM · Seaborn
